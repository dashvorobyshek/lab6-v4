## Описание выполнения заданий

### Средняя сложность №4

В `task4.py` создано Flask-приложение с маршрутом `GET /`.

HTML-страница содержит таблицу технологий. Строки формируются циклом Jinja2 из списка словарей. Используются заголовки столбцов и простое CSS-оформление.

Шаблон находится внутри Python-файла и обрабатывается функцией `render_template_string()`.

### Средняя сложность №6

В `task6.py` создано приложение FastAPI с маршрутом `GET /`.

Ответ возвращается в формате JSON:

```json
{
  "message": "Hello, FastAPI!"
}
```

Приложение запускается через Uvicorn.

### Средняя сложность №10

В `task10.py` создано приложение FastAPI для просмотра и добавления задач.

| Метод | Маршрут | Действие |
|---|---|---|
| GET | `/` или `/tasks` | Показать список задач |
| POST | `/tasks` | Добавить задачу |

У задачи есть номер `id`, название `title` и признак выполнения `completed`. Название должно содержать от 1 до 100 символов после удаления пробелов по краям. По умолчанию задача считается невыполненной (`completed: false`).

При добавлении API возвращает созданную задачу с кодом `201`. Задачи хранятся в памяти. После перезапуска в списке снова остаётся одна демонстрационная задача.

### Повышенная сложность №5

В `task5pov.py` создано приложение FastAPI для работы с заметками. Каждая заметка содержит номер `id`, заголовок `title` и текст `text`.

| Метод | Маршрут | Действие |
|---|---|---|
| GET | `/` или `/notes` | Показать список заметок |
| POST | `/notes` | Добавить заметку |
| PUT | `/notes/{note_id}` | Заменить заголовок и текст заметки |
| DELETE | `/notes/{note_id}` | Удалить заметку |

Заголовок и текст обязательны. Если одно из полей пустое или состоит только из пробелов, API возвращает код `422`. При попытке изменить или удалить отсутствующую заметку возвращается код `404`.

Заметки хранятся в памяти. После перезапуска приложения в списке снова остаётся одна демонстрационная заметка.

### Повышенная сложность №9

В `task9pov.py` приложение подключается к SQLite через SQLAlchemy Core. Таблица `students` описана с помощью `Table` и содержит поля `id`, `name` и `group_name`. При запуске программа создаёт таблицу, если её ещё нет.

| Метод | Маршрут | Действие |
|---|---|---|
| GET | `/` или `/students` | Показать список студентов |
| POST | `/students` | Добавить студента |

Для чтения используется `select()`, для добавления — `insert()`. Запись выполняется внутри `engine.begin()`, который подтверждает транзакцию при успешном завершении. Имя и группа проверяются с помощью Pydantic.

База `lab6.sqlite3` находится рядом с программой. Добавленные записи сохраняются после перезапуска сервера. Файл базы исключается из Git через `.gitignore`.
